🏷️ Meta Optimization

Only pages that are actually underperforming in the selected period (ranking drop, CTR drop, or CTR well below the position-expected benchmark -- same signal as Reoptimizer's decliners). Title/meta description/meta keywords suggestions are AI-written on demand with a before/after SERP preview; schema markup issues are flagged for manual fixing (no API to apply those automatically).

✍️ Content Reoptimization

LSI/secondary-keyword gaps and a suggested new paragraph for blog posts that are underperforming in the selected period -- shown as a real before/after of the end of the post. Live Apply is scoped to a safe, additive edit (appending the paragraph); nothing existing gets rewritten in place.

🔗 Internal Linking

For pages underperforming in the selected period (blog posts AND static/project pages): the internal links currently on the page, and suggested new links to add -- target, anchor text, and why it should help traffic and crawling. Live Apply works for blog posts with a verified anchor; everything else is copy-paste.

🔍 SEO Audit

A Screaming-Frog-style technical crawl of every page on the site (not just GSC-underperforming ones): broken links, redirect chains, missing/duplicate canonical tags, heading hierarchy problems, sitewide duplicate titles/descriptions, missing image alt text, and orphan pages. Canonical and duplicate-tag fixes are AI-written on demand with live Apply + Undo; everything else is flagged for manual fixing or copy-paste (no safe API to auto-apply those).
